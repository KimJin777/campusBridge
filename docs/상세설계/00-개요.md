| fallback | 근거를 찾지 못했을 때 "모름 + 담당 부서 안내"로 끝내는 경로 |

## 공통 규약

- **언어·런타임**: Python 3.12, uv(`pyproject.toml` + `uv.lock`), 프론트는 빌드 도구 없는 HTML/CSS/JS
- **시각**: 저장은 UTC ISO 8601, 화면 표시는 KST
- **ID**: `thread_id`·`request_id`는 프론트가 발급하는 UUID v4, `turn_id = {thread_id}_{request_id}`. 조문은 `article_id`(01 문서)
- **계약 버전**: API/SSE `schema_version = 1`(04 문서). 공통 스키마(Pydantic)는 `backend/domain/`(evidence·thread·answer·errors)과 `backend/api/schemas.py`를 **단일 원본**으로 두고 Agent·API·테스트가 함께 import
- **보존**: 모든 저장 문서에 `expires_at`(TTL 필드)을 둔다(01 문서 5절)
- **설정**: 모든 환경값은 `backend/app/config.py` 한 곳에서 환경변수로 읽는다. 코드에 프로젝트 ID·모델명·URL 하드코딩 금지
- **외부 호출**: Gemini·Vertex·HTTP 호출은 공통 래퍼(재시도·타임아웃·로깅)를 거친다(07 문서)
- **로깅**: 구조화 로그(JSON) — `thread_id`, `turn_id`, `node`, `elapsed_ms`, `error`
- **개인정보**: 저장 전 마스킹(02 문서 5절), 원문 대화 전체는 저장하지 않는다
